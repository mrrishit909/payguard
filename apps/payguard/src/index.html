How a review runs

  1. Import

    Load the application as JSON or the documented CSV. Files over 1 MiB, malformed rows or unknown columns are refused whole, so a previous report is never half replaced.

  2. Reconcile

    Each line is rebuilt from contract value, approved change orders, completed work, stored materials and per-line retainage, then compared with the claimed amount to the cent.

  3. Resolve

    Correct the claim or attach the missing waiver and run the check again. A finding leaves the list only when a new run no longer produces it; your notes and the original run stay on record.

Method and limits

Every figure on this page comes from the same calculation the review workspace uses, run on fictional sample files in your browser. Nothing is uploaded.
