# Atlas execution rules

This repository is coordination state, not the application monorepo. Preserve unrelated repositories.

Claude implements substantial product code; Codex orchestrates and independently verifies. Only included Claude Max allowance; usage credits remain disabled. Stop on quota exhaustion, checkpoint in GitHub, never purchase credits or enable API billing. No paid infrastructure or overages.

Every assignment must name repository/branch/paths, scope, inputs, security boundaries, acceptance commands, evidence and completion. No recursive Claude/Codex loops. Keep agent concurrency small (initial Claude concurrency one). No skill installation before source/license/security review. Use website-playbook for website decisions. Do not label demo production-ready or claim legal authority.

No private Actions dispatch before account quota and zero-spend settings are verified. Do not commit auth/cache/transcripts. Commit concise sanitized evidence. Local workspace is small and expendable; GitHub is durable state.
